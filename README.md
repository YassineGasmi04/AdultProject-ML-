# Adult Income – Projet Machine Learning

Analyse et prédiction du revenu (≤50K / >50K) à partir du dataset Adult Census Income (UCI).

## Ma partie : la situation familiale
- Variable principale : relationship
- Variable secondaire : marital-status
- Objectif : comprendre et prédire le revenu selon la situation familiale

## Contenu du notebook
1. Nettoyage des données (doublons, valeurs manquantes)
2. Transformation des données (encodage, séparation train/test, normalisation)
3. Sélection des caractéristiques (matrice de corrélation, seuil 0,1)

## Outils
Python, pandas, scikit-learn, matplotlib, seaborn (Google Colab)
